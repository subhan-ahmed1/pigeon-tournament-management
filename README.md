A complete management system for high flyer pigeon tournaments. Supports multi-day events, player registration, flight tracking, and performance ranking. Built with Next.js and MySQL.
This web application designed for managing high flyer pigeon tournaments, specifically tailored for Pakistani pigeon clubs. It allows tournament organizers to create multi-day events, track pigeon flight durations, manage player registrations, record arrival times, and generate performance-based rankings. The system supports special pigeon categories and traditional titles like Akhri Bahadur and Pehla Bahadur.
